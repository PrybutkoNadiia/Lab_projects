# Лабораторна робота 3.3 — коло

Реалізація відповідає умові з фото: клас «Коло», шість об’єктів, обчислення площі й довжини окружності та виведення даних.

## Структура

- `Lab_3_3.DAL` — сутність для зберігання кіл, репозиторій і чотири постачальники серіалізації.
- `Lab_3_3.BLL` — перевірка даних, операції додавання та видалення, обчислення, перетворення між рівнями.
- `Lab_3_3.PL` — консольне меню та модель для показу й введення даних.

## Запуск

З кореневої папки рішення виконайте:

```powershell
dotnet run --project .\Lab_3_3.PL
```

На початку оберіть формат і файл. Доступні бінарний, XML, JSON і власний текстовий формат. У меню можна переглянути, додати й видалити кола, зберегти шість прикладів або перевірити серіалізацію масиву та колекції.
