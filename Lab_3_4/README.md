# Лабораторна робота 3.4 — варіант 4

## Умова варіанта

- Відсортувати одновимірний масив символів за спаданням і викликати сортування через делегат.
- Реалізувати обмежену чергу з додаванням і видаленням елементів.
- Сповістити про спробу додати елемент у заповнену чергу.

## Запуск

Потрібен .NET 10 SDK. У теці проєкту виконайте:

```text
dotnet run
```

Програма показує результат сортування через лямбда-вираз та анонімний метод, а також демонструє переповнення черги, видалення та повторне додавання елемента.

## Структура рішення

- `Program.cs` — приклади використання делегатів і черги.
- `Collections/BoundedQueue.cs` — черга заданої місткості; `Enqueue` повертає `false` і генерує подію, якщо черга повна.
- `Events/QueueOverflowEventArgs.cs` — аргументи події з відхиленим елементом і станом черги.
- `Handlers/QueueOverflowHandler.cs` — окремий клас-обробник зі стандартною сигнатурою `EventHandler<TEventArgs>`.

## Контрольні запитання

1. **Що таке делегат?** Типобезпечне посилання на метод або список методів із сумісною сигнатурою. Делегат можна передавати як значення та викликати.
2. **Як оголосити й викликати делегат?** Наприклад: `Func<char[], char[]> sorter = values => values.OrderByDescending(c => c).ToArray();`, після чого викликати `sorter(characters)`. У програмі також показано анонімний метод.
3. **З чого складається делегат?** Він зберігає посилання на методи виклику та, для методів екземпляра, відповідні цільові об’єкти; multicast-делегат містить список викликів.
4. **Як забезпечується контроль типів?** Сумісність типів параметрів і результату перевіряється компілятором відповідно до сигнатури делегата.
5. **У що розгортається делегат?** У тип-нащадок `System.MulticastDelegate`; екземпляр містить цільовий об’єкт, метод виклику та список викликів (для multicast-делегатів).
6. **Що таке анонімний метод?** Метод без окремого імені, оголошений виразом `delegate` і прив’язаний до сумісного делегата.
7. **Що таке лямбда-вираз?** Короткий синтаксис анонімної функції: `параметри => вираз` або `параметри => { оператори; }`. Наприклад, у роботі: `values => values.OrderByDescending(c => c).ToArray()`.
8. **Які побічні ефекти можливі?** Анонімні методи й лямбди можуть захоплювати змінні з зовнішньої області видимості. Такі змінні зберігаються довше, ніж очікується, спільно змінюються або захоплюють `this`; підписані на подію лямбди також можуть утримувати об’єкти, доки обробник не буде відписаний.
